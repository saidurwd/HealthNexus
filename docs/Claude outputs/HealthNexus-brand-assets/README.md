# HealthNexus brand assets (v1.0)

Concept: a medical cross built as a connected hub — a central "nexus" node linked to four care nodes.
Palette: Blue #1E6FD9 -> Teal #12B5A5 (mark gradient), Navy #0B2A4A (wordmark), teal text #0E9F92 (light bg) / #5EEAD4 (dark bg).
Wordmark: Inter Display Bold (OFL), converted to outlines — no font needed to display the SVGs.

svg/     healthnexus-logo (horizontal, light bg) · -reversed (dark bg) · -stacked · -mark · -mark-white · app-icon-maskable
png/     transparent PNG exports of the logos
favicon/ favicon.svg, favicon.ico (16/32/48), PNG sizes, apple-touch-icon, Android icons, site.webmanifest

## Laravel / HTML <head>  (copy favicon/ into public/favicon/)
<link rel="icon" href="/favicon/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/favicon/favicon.ico" sizes="48x48">
<link rel="apple-touch-icon" href="/favicon/apple-touch-icon.png">
<link rel="manifest" href="/favicon/site.webmanifest">
<meta name="theme-color" content="#1E6FD9">

Clear space: keep at least the height of one outer node (about 1/8 of the mark) free around the logo.
Minimum size: horizontal logo 120 px wide; use favicon.svg for anything under 32 px.
Do not recolour the gradient, stretch, or place the standard logo on busy photos.

Provenance: hand-authored SVG generated by script (Recraft was not available in that session).
