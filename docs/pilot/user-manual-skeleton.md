# User manual — skeleton (Bangla and English)

Write each chapter in both languages from the same screenshots. One page per task; screenshots from the TRAINING organization (`php artisan demo:build`).

1. **Getting started** — signing in, two-step login, choosing organization and branch, changing language, changing password, the search box (Ctrl+K), keyboard shortcuts (?), what the TRAINING banner means.
2. **Reception** — find a patient, register a patient (duplicate check), book / reschedule / cancel, check-in, queue, print slip. *Quick-start card: Receptionist.*
3. **Doctor (OPD)** — queue, consultation, vitals, diagnosis, prescription, tests, follow-up, printing. *Card: Doctor.*
4. **Nursing and wards** — My Patients, observations, medicine administration (five checks), handover, alerts. *Card: Nurse.*
5. **Admission, beds and discharge (IPD)** — request, admit, bed board, transfer, leave, discharge clearances.
6. **OT and ICU** — surgery request to scheduling, safety checklist, operative note; ICU episode, flowsheet, alerts.
7. **Laboratory and radiology** — worklists, specimens, results, critical results, reports. *Cards: Laboratory, Radiology.*
8. **Pharmacy** — prescription queue, dispensing, stock, batches, controlled drugs, recalls. *Card: Pharmacist.*
9. **Billing and cashier** — session, invoices, payments, receipts, refunds, discounts. *Card: Cashier.*
10. **Management** — dashboards, reports and exports, audit, imports. *Card: Manager.*
11. **Administration** — users and roles, settings, data import, modules, downtime kit.
12. **When something goes wrong** — error reference code, who to call (support sheet), downtime forms, back-entering after an outage.
13. **Glossary** — the one-word-per-concept list (guideline Appendix G).
